# apniwebsite

Full-stack portfolio website for `apniwebsite.com`.

## Stack

- Frontend: React + Vite
- Backend: Node.js + Express

## Structure

- `client/` - React frontend
- `server/` - Express backend

## Suggested commands

Install dependencies separately:

- `cd client && npm install`
- `cd ../server && npm install`

Run in development:

- `npm run dev` inside `client`
- `npm run dev` inside `server`

## Current features

- white professional landing page
- package pricing section
- category-based portfolio section
- backend-powered content endpoint
- enquiry form posting to Express API
